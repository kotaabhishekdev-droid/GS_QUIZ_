# Gender Studies Quiz — GitHub Pages

Static unit-wise quiz app built only from the uploaded `QB 1.pdf`.

- Unit 1: 40 MCQs
- Unit 2: 40 MCQs
- Unit 3: 20 MCQs
- Full quiz: 100 MCQs
- LAQ revision
- Instant answer feedback
- Score and unit breakdown
- Dark mode
- Mobile responsive
- No backend / database / API / framework

## Deploy
Create a GitHub repository, upload `index.html`, `style.css`, `app.js`, and `questions.json` to the root, then use **Settings → Pages → Deploy from a branch → main → / (root)**.

Keep all four files in the same folder because the app loads `questions.json` with a relative path.
